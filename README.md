# Cat Reviews Its Human

Entry for the make.fun bounty [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

One funny single-line one-star review, written by a house cat about its human, under 200 characters. `main.ts` writes the line to `/output/entry.txt` after validating it (1 to under 200 characters, a single line, not only white space), then reads it back to confirm the file matches.
